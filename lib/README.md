# 🔒 Proprietary Neural Engine

The `pohyi_neural_core_v1.dll` file contained in this directory is the compiled, closed-source cognitive reasoning engine for the Pohyi architecture.

Due to the integration of proprietary vector-search algorithms and enterprise-licensed machine learning components, the source code for this specific module is **not** open source. 

The Go-based orchestrator (`pohyid`) interfaces with this DLL via memory-mapped IPC to ensure zero-latency intelligence routing and contextual analysis.
